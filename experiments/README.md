# Late competition experiments

Recovered original source for V125, V128 and V137–V152. V141 fits the weekend
correction selected for V142. V142 is the last reported best submission;
V143–V152 did not replace it.

These are the original research scripts and frozen plans. They depend on
private `runtime/` files, including earlier models and validation arrays.
See [running the code](../docs/running.md) for the scope of recovery.

Research-archive bundling scripts are omitted; model fitting, confirmation and
submission construction are retained. The gaps between version numbers reflect
what was recovered, not a claim that the missing experiments never existed.
